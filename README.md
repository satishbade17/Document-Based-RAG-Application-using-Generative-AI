# 📚 PDF Question Answering using RAG

A **Retrieval-Augmented Generation (RAG)** application that allows users to upload PDF documents and ask questions about their content.

## 🚀 Project Workflow

PDF Document
↓
Text Extraction
↓
Text Chunking
↓
Embeddings
↓
ChromaDB
↓
Similarity Retrieval
↓
LLM
↓
AI Generated Answer

## 🛠️ Technologies

* Python
* Streamlit
* LangChain
* ChromaDB
* Transformers
* Embeddings
* RAG

## 🎯 Objective

The objective of this project is to build a document-based question-answering system where relevant information is retrieved from uploaded documents and provided to the AI model for generating answers.

## 💡 Key Learning

Through this project, I learned how document retrieval, vector databases, embeddings, and generative AI can be combined to create a practical RAG application.
